# EPIC 8 - Story 8.4

## Sparse Data Lanes

## Goal

Render lower-density inference surfaces such as sections, symbolic phrase windows, chords, pattern occurrences, and event windows.

## Inputs

- `data/analysis/<Song - Artist>/artifacts/layer_b_symbolic.json`
- `data/analysis/<Song - Artist>/artifacts/layer_a_harmonic.json`
- `data/analysis/<Song - Artist>/artifacts/layer_d_patterns.json`
- `data/analysis/<Song - Artist>/artifacts/section_segmentation/sections.json`
- `data/analysis/<Song - Artist>/artifacts/event_inference/events.machine.json`

## Acceptance Criteria

- Sparse lanes render directly from artifact timing windows.
- The symbolic phrases lane reads `phrase_windows[]` from `layer_b_symbolic.json` and displays all windows grouped by `phrase_group_id`.
- Symbolic phrase windows stack into multiple rows when overlaps occur, using the same compaction logic as machine event windows.
- Clicking or selecting a region affects only browser playback/navigation state.
- No region interaction writes state into generated-data directories.

## UI v2 component map (plan item 10)

The React + TypeScript rebuild (`docs/web-ui/ui-rebuild/`) implements this story in:

- `ui/src/timeline/SparseLane.tsx` — reusable block-lane body with hit regions + row-packing.
- `ui/src/timeline/laneContent.ts` — per-lane content adapters (`humanHints`, `sections`, `chords`, `patterns`, `phrases`, …).
