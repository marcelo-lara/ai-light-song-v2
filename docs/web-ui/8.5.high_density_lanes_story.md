# EPIC 8 - Story 8.5

## High-Density Lanes

## Goal

Render dense inference surfaces such as seven-band FFT intensity, drum transients, and energy profiles without relying on output-side projections.

## Inputs

- `data/analysis/<Song - Artist>/artifacts/essentia/fft_bands.json`
- `data/analysis/<Song - Artist>/artifacts/symbolic_transcription/drum_events.json`
- `data/analysis/<Song - Artist>/artifacts/layer_c_energy.json`

## Acceptance Criteria

- Dense lanes use artifact-first inputs.
- The FFT lane renders seven stacked low-to-high spectral rows from 50 ms artifact frames.
- Rendering is bounded to the visible timeline region when practical.
- No debugger-generated cache or export is written into generated-data folders.

## UI v2 component map (plan item 10)

The React + TypeScript rebuild (`docs/web-ui/ui-rebuild/`) implements this story in:

- `ui/src/timeline/CanvasLane.tsx` — DPR-aware canvas lane body + ResizeObserver redraw.
- `ui/src/timeline/laneRenderers.ts` — `fft` / `rms` / `env` / `drums` / `energy` renderers.
- `ui/src/timeline/palette.ts` — `FFT_BAND_HUES`, `SOURCE_COLORS`, lane heights (ported verbatim).
