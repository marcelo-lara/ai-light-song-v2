# EPIC 8 - Story 8.3

## DAW-Style Lane Architecture

## Goal

Create a shared lane container for artifact visualization in the internal debugger.

## Inputs

- playback time from Story 7.2
- `data/analysis/<Song - Artist>/artifacts/`
- selected helper files from `data/analysis/<Song - Artist>/`

## Processing Steps

1. Define a fixed lane-label region and a synchronized timeline region.
2. Maintain shared zoom and scroll state across loaded lanes.
3. Support toggling lanes on and off without mutating source data.

## Output

- browser-only lane layout state inside the debugger

## Acceptance Criteria

- All lanes share the same time axis.
- Lane enablement is local UI state only.
- The debugger remains read-only against generated data.

## UI v2 component map (plan item 10)

The React + TypeScript rebuild (`docs/web-ui/ui-rebuild/`) implements this story in:

- `ui/src/timeline/TimelineGrid.tsx` — the 212px label column + sticky Segments/Bars header + shared playhead.
- `ui/src/timeline/laneState.ts` — lane registry (`visible` / `expanded`, localStorage-persisted).
- `ui/src/timeline/LaneList.tsx` — show/hide + expand/collapse panel.
- `ui/src/timeline/CanvasLane.tsx` / `SparseLane.tsx` — the two lane-body kinds.
