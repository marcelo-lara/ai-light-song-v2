# EPIC 8 - Story 8.6

## Semantic Zoom and Performance Guardrails

## Goal

Protect the debugger from unbounded rendering cost while preserving useful inference visibility across zoom levels.

## Acceptance Criteria

- Zoom state is shared across lanes.
- Dense artifact views can cluster or summarize data when zoomed far out.
- Rendering policy stays browser-local and does not create new generated files.

## UI v2 component map (plan item 10)

The React + TypeScript rebuild (`docs/web-ui/ui-rebuild/`) implements this story in:

- `ui/src/timeline/zoom.ts` — `pxPerBar` clamp/step, `fitToWidthPxPerBar`, `semanticZoom` threshold table.
- `ui/src/timeline/follow.ts` — follow-playhead scroll maths.
- `ui/src/app/keymap.ts` — `+ - [ ]` → zoom in/out, `f` → fit-to-width (see §10 deviation note).
